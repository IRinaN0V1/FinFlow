# FinFlow — Персональный трекер финансов

REST API сервис для управления личными финансами. Позволяет пользователям отслеживать доходы и расходы, контролировать баланс.

## О проекте

FinFlow — это учебный проект, демонстрирующий навыки разработки на **Java** и **Spring Boot**. Сервис предоставляет API для:
- Создания пользователей
- Добавления доходов и расходов
- Просмотра текущего баланса

## Технологии

| Технология | Назначение |
|------------|------------|
| Java 21 | Основной язык программирования |
| Spring Boot 4.0.4 | Фреймворк для создания приложения |
| Spring Data JPA | ORM, работа с базой данных |
| PostgreSQL 17 | Реляционная база данных |
| Docker / Docker Compose | Контейнеризация и оркестрация |
| JUnit 5 / Mockito | Юнит-тестирование |
| Maven | Сборка проекта |

## Запуск проекта

### Требования

- Java 21
- Docker Desktop (для запуска через Docker)
- Maven (или встроенный Maven Wrapper)

# Запуск через Docker

Сборка приложения:

./mvnw clean package

Запуск PostgreSQL и приложения:

docker-compose up --build

Приложение будет доступно: 

http://localhost:8080

Остановка:

docker-compose down
